**Abrir el graficador:** https://castxno-sys.github.io/graficador-campos-vectoriales/

- `index.html` — graficador interactivo (F = ∇f, G = ⟨−y, x⟩ o un campo personalizado): vector en un punto, prueba de Clairaut, circulación y comparación de caminos.

- `fig*.png` — figuras usadas en la exposición.
